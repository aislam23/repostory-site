# repostory.me

Статический сайт Telegram-бота [@repostorybot](https://t.me/repostorybot): главная, политика конфиденциальности,
условия использования и инструкция по удалению данных (RU/EN). Публикуется на GitHub Pages из папки `site/`
(workflow `.github/workflows/pages.yml`), домен `repostory.me` через Cloudflare DNS.

Источник правды — папка `site/` в репозитории бота; сюда копируется как есть.
